# रामकोला टाइम्स — सेटअप गाइड (एक-एक स्टेप)

कुल समय: लगभग 30–40 मिनट। खर्च: ₹0 (GitHub Pages + Supabase Free)।

## वेबसाइट में क्या-क्या है

| पेज | कौन देखेगा | काम |
|---|---|---|
| `index.html`, `article.html` | सब लोग | प्रकाशित खबरें, श्रेणी, खोज, WhatsApp शेयर |
| `login.html` | स्टाफ / एडमिन | लॉगिन (खाता सिर्फ़ एडमिन बनाता है) |
| `staff.html` | स्टाफ | अपना प्रमाणपत्र देखना, खबर लिखना, ड्राफ्ट/भेजना, स्थिति देखना |
| `admin.html` | एडमिन | स्टाफ जोड़ना, प्रमाणपत्र अपलोड, खबर प्रकाशित/अस्वीकार |

**खबर का सफ़र:** स्टाफ लिखता है → "समीक्षा के लिए भेजें" → एडमिन "प्रकाशित" करता है → पब्लिक साइट पर दिखती है।
स्टाफ खुद खबर प्रकाशित **नहीं** कर सकता — यह नियम डेटाबेस (RLS) में लगा है, सिर्फ़ बटन छिपाकर नहीं।

---

## स्टेप 1 — Supabase खाता और प्रोजेक्ट बनाएँ

1. <https://supabase.com> खोलें → **Start your project** → GitHub या ईमेल से साइन-अप करें।
2. **New project** दबाएँ।
3. Name: `ramkola-times`। **Database Password** कोई मज़बूत पासवर्ड डालें और कहीं लिख लें।
4. Region: **Mumbai (ap-south-1)** चुनें (भारत में तेज़)।
5. Plan: **Free** → **Create new project**। 1–2 मिनट रुकें।

## स्टेप 2 — डेटाबेस तैयार करें (SQL)

1. बाएँ मेन्यू में **SQL Editor** → **New query**।
2. इस फ़ोल्डर की `supabase_setup.sql` फ़ाइल खोलें, **पूरा** कॉपी करें और वहाँ paste करें।
3. **Run** दबाएँ। नीचे "Success" आना चाहिए।
   - इससे तीन टेबल (profiles, certificates, news), सुरक्षा नियम और दो storage बकेट (`certificates` निजी, `news-images` सार्वजनिक) बन जाते हैं।

## स्टेप 3 — ईमेल कन्फ़र्मेशन बंद करें (ज़रूरी)

एडमिन जब स्टाफ जोड़ता है तो स्टाफ को कन्फ़र्म-ईमेल नहीं जाता, इसलिए इसे बंद रखना होगा।

1. **Authentication** → **Sign In / Providers** (या **Providers**) → **Email**।
2. **Confirm email** को **OFF** करें → **Save**।

> सुरक्षा: कोई बाहरी व्यक्ति सीधे API से खाता बना भी ले तो उसका `active = false` रहता है, इसलिए वह कुछ नहीं कर सकता। सिर्फ़ एडमिन ही किसी को सक्रिय करता है।

## स्टेप 4 — पहला एडमिन बनाएँ

1. **Authentication** → **Users** → **Add user** → **Create new user**।
2. अपना ईमेल और पासवर्ड डालें, **Auto Confirm User** ✔ करें → Create।
3. **SQL Editor** में नई query खोलकर यह चलाएँ (ईमेल अपना डालें):

```sql
update public.profiles
  set role = 'admin', active = true, full_name = 'संपादक'
  where email = 'आपका@email.com';
```

## स्टेप 5 — चाबियाँ (URL और anon key) और चैनल की जानकारी भरें

1. **Project Settings** (⚙️) → **API** (या **Data API / API Keys**)।
2. **Project URL** कॉपी करें, जैसे `https://abcd1234.supabase.co`।
3. **anon / public** key (या "Publishable key") कॉपी करें।
4. `js/config.js` खोलकर दोनों जगह बदलें:

```js
SUPABASE_URL: "https://abcd1234.supabase.co",
SUPABASE_ANON_KEY: "यहाँ आपकी anon key",
```

5. उसी फ़ाइल में `SITE` हिस्से में चैनल का फ़ोन, WhatsApp, ईमेल, पता, Facebook/YouTube लिंक और "हमारे बारे में" का टेक्स्ट भरें (खाली छोड़ेंगे तो वह हिस्सा साइट पर नहीं दिखेगा)।

❌ **`service_role` / secret key कभी इस फ़ाइल में न डालें।** anon key सार्वजनिक रहती है, वह सुरक्षित है।

## स्टेप 6 — GitHub पर डालें

1. <https://github.com> पर खाता बनाएँ → **New repository**।
2. Name: `ramkola-times` → **Public** → Create।
3. **uploading an existing file** लिंक दबाएँ और इस फ़ोल्डर की **सारी फ़ाइलें और फ़ोल्डर** (`index.html`, `css`, `js` आदि) खींचकर डालें।
   - ध्यान दें: `index.html` रिपॉज़िटरी के सबसे ऊपर (root) में होनी चाहिए, किसी उप-फ़ोल्डर में नहीं।
4. **Commit changes** दबाएँ।

## स्टेप 7 — GitHub Pages चालू करें

1. रिपॉज़िटरी में **Settings** → बाएँ **Pages**।
2. **Source:** *Deploy from a branch* → Branch: **main**, folder: **/ (root)** → **Save**।
3. 1–2 मिनट बाद वही पेज आपका लिंक दिखाएगा: `https://आपका-नाम.github.io/ramkola-times/`

## स्टेप 8 — Supabase को साइट का पता बताएँ

1. Supabase → **Authentication** → **URL Configuration**।
2. **Site URL** में अपना GitHub Pages लिंक डालें → **Save**।

## स्टेप 9 — जाँच करें (इसी क्रम में)

1. अपनी साइट खोलें → ऊपर "स्टाफ / एडमिन लॉगिन" → एडमिन ईमेल से लॉगिन। `admin.html` खुलना चाहिए।
2. **स्टाफ** टैब में एक टेस्ट स्टाफ जोड़ें (नाम, ईमेल, पासवर्ड)।
3. **प्रमाणपत्र** टैब में उस स्टाफ के नाम एक PDF/फ़ोटो अपलोड करें।
4. लॉगआउट → स्टाफ के ईमेल से लॉगिन → **मेरे प्रमाणपत्र** में फ़ाइल दिखे।
5. **खबर लिखें** → "समीक्षा के लिए भेजें"।
6. लॉगआउट → एडमिन से लॉगिन → **अनुमोदन** टैब → "प्रकाशित करें"।
7. मुख्य पेज खोलें — खबर दिखनी चाहिए।

## रोज़ के काम

- **नया स्टाफ:** एडमिन → स्टाफ टैब → फ़ॉर्म भरें → ईमेल/पासवर्ड स्टाफ को भेजें।
- **स्टाफ हटाना:** "निष्क्रिय करें" दबाएँ (वह लॉगिन नहीं कर पाएगा, उसकी पुरानी खबरें सुरक्षित रहेंगी)।
- **पासवर्ड भूले:** Supabase → Authentication → Users → उस यूज़र पर ⋯ → **Send password recovery** या नया पासवर्ड सेट करें।
- **खबर में सुधार चाहिए:** "अस्वीकार" दबाकर कारण लिखें; स्टाफ को वह टिप्पणी दिखेगी और वह सुधारकर दोबारा भेज सकता है।

## Free प्लान की सीमाएँ (जान लें)

- **7 दिन तक कोई गतिविधि न हो तो Supabase प्रोजेक्ट "Pause" हो जाता है।** साइट पर खबरें दिखनी बंद हो जाएँगी। Supabase Dashboard में **Restore project** दबाने पर वापस चालू हो जाता है। रोज़ कुछ विज़िटर आते रहें तो आमतौर पर दिक्कत नहीं होती।
- Storage लगभग 1 GB, डेटाबेस लगभग 500 MB। खबर की फ़ोटो अपने-आप छोटी (अधिकतम 1200px) हो जाती है, इसलिए बहुत चलेगा।
- प्रमाणपत्र 5 MB तक, खबर की फ़ोटो 2 MB तक।
- GitHub Pages पर कस्टम डोमेन (जैसे `ramkolatimes.in`) बाद में Settings → Pages → Custom domain से जोड़ सकते हैं।

## अगर कुछ न चले

| समस्या | कारण / हल |
|---|---|
| ऊपर पीली पट्टी "config.js में URL नहीं डाली" | स्टेप 5 दोबारा करें |
| लॉगिन पर "आपका खाता सक्रिय नहीं" | एडमिन के लिए स्टेप 4 का SQL चलाएँ; स्टाफ के लिए एडमिन से सक्रिय करवाएँ |
| स्टाफ जोड़ते समय error / स्टाफ लॉगिन नहीं कर पा रहा | स्टेप 3 (Confirm email OFF) जाँचें |
| "अनुमति नहीं है" | `supabase_setup.sql` पूरा Run हुआ या नहीं देखें |
| खबर पब्लिक पर नहीं दिख रही | एडमिन ने "प्रकाशित" किया या नहीं देखें |
| साइट खाली / 404 | `index.html` repo के root में है? Pages चालू है? |
